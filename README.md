# Night Shift — CCTV Anomaly Watch

Watch 10 security cameras from 12 AM to 6 AM. When something changes, draw a red circle around it with the mouse.

## Run
Open `index.html` in a browser. No build step or server is needed.

1. Put 20 images per room in `assets/cam01/` … `assets/cam10/`, named `01.jpg` … `20.jpg` (`.png`, `.jpeg` and `.webp` also work).
2. Use 16:9 images (for example 1280×720).
3. Open `editor.html`. For each anomaly image, drag from the anomaly's centre outward to circle it. Leave normal images without a circle.
4. Click **Download anomalies.js**, then replace `js/anomalies.js` with the downloaded file.

Until at least one anomaly is marked, the game runs in **DEMO MODE** with placeholder anomalies.

## How it plays
- All in-game text is Thai. An intro screen explains the story and rules.
- The game goes full screen on start. Leaving full screen pauses it.
- Switch cameras with the on-screen left/right arrows, `← →` or `1`–`0`.
- Every 20–35 s (faster late at night), a camera you are *not* looking at switches to an anomaly image.
- Each anomaly gives you **10 s**: at 5 s the screen starts shaking, at 9 s it shakes hard, and at 10 s a jumpscare ends the game.
- Draw a circle around the anomaly to report it. A hit stops its timer immediately. A miss locks reporting for 3 s.
- Reach 06:00 = win. `Esc` cancels a drawing, `P` pauses, `M` mutes.

All timings and limits are in `js/config.js`.

## Files
- `index.html`, `css/style.css`, `js/game.js` — the game
- `editor.html`, `js/editor.js` — the anomaly marking tool
- `js/config.js` — settings and camera names
- `js/anomalies.js` — anomaly locations (generated by the editor)
- `js/common.js` — shared image loading and placeholder drawing

## Audio
All sounds are team-made: phone recordings in `HomeMadeSoundeffect/` plus code synthesis, built into `assets/audio/` by `py tools/build_audio.py` (details in `assets/audio/CREDITS.md`). Playback code is in `js/audio.js`.
- Title music, then main shift music with room ambience
- Danger music fades in when 3 anomalies are unreported at once
- Static on camera switch and while a report is sending
- Sounds for correct and wrong reports, warning, game over and win
- Random creepy noises every 30–80 s
- `M` or the panel button mutes all sound
